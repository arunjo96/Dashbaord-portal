# Intranet Dashboard UI

A modern, responsive Intranet / Portal Dashboard UI built using HTML5, CSS3, and JavaScript, focused on clean layout, usability, and enterprise-style design.

This project includes a fixed header, collapsible sidebar, dashboard widgets, calendar integration styling, feed sections, resource hub, gallery slider styles, and footer.
---

## Features

✅ Fixed Header with search & user profile dropdown

✅ Collapsible Sidebar (desktop-friendly)

✅ Clean Dashboard Layout (Grid + Flexbox)

✅ Quick Links Cards with hover animations

✅ Task Management Card UI

✅ FullCalendar custom styling support

✅ Tooltip-ready styles (Tippy.js compatible)

✅ News Feed & Knowledge Management sections

✅ Resource Hub with department tabs

✅ Gallery / Slider pagination styling (Swiper-ready)

✅ Social Media widgets

✅ Sticky Footer + Scroll-to-top button

✅ Fully responsive & scalable UI foundation

---

## Tech Stack

--HTML5 – Semantic structure

--CSS3 – Custom properties, Grid, Flexbox

--Javascript, Jquery – Function action the UI

--Google Fonts – Inter & Montserrat

--Font Awesome – Icons

--Swiper.js – Gallery slider

--FullCalendar.js  – Calendar UI

--Tippy.js – Tooltips
